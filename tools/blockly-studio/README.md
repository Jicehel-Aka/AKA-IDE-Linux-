# 🧩 Studio Blockly Gamebuino AKA

Ce dossier documente les outils de développement visuel pour la console portable Gamebuino AKA.

## Fonctionnalités
- Éditeur visuel par blocs basé sur Google Blockly.
- Générateur automatique MicroPython (`main.py`) et C++ Arduino / PlatformIO.
- Simulateur interactif Gamebuino AKA émulant l'écran couleur 320×240, les 4 NeoPixels RGB, le buzzer audio et le vibreur haptique.
- Éditeur de sprites 16×16 avec export bitmap en direct.
- 9 tutoriels interactifs complets traduits en 6 langues (Français, Anglais, Allemand, Italien, Portugais, Espagnol).
